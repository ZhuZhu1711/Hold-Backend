## 使用变化

- 分析页同 lot 表只加粗**当前片的当前站点**。刚建单、该站 rawdata 还没到位时，不再把加粗落到同片其它站点；该站会留一行橙色占位，并醒目提示「rawdata 还没到位，请稍等」，**不影响继续处置**。
- 同 lot 表支持**点击表头排序**。良率、BIN 数量/比率按数值排；片号按自然序（如 `#9` 在 `#10` 前面）；空值和「rawdata未到位」排在后面。切换「数量/比率」「code/defect」后仍记住刚才排的列。
- 同 lot 表可**导出 CSV**（工具栏「导出 CSV」）。导出的是当前看到的表格，含排序以及数量/比率、code/defect 切换结果；UTF-8（带 BOM），Excel 可直接打开中文。
