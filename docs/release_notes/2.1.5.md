# Hold 处置客户端 2.1.5

发布日期：2026-10-12

请到软件中心安装本版本。未更新的正式客户端将无法继续使用。

---

## 使用变化

- 工具菜单新增「设置」，保存在本机。可勾选待办列表显示哪些列，并调整每页条数、自动刷新、空闲自动退出、启动时是否最大化，以及关闭主窗口时是否最小化到托盘。自动刷新和空闲退出都可以选「关闭」。
- 管理员可以登录客户端，查看全部在线 Hold 并打开分析；处置不可用。
- 分析页 bysite 按 testlog CSV 的列名解析。列顺序变化时，不再把 bysite 解析成空表。
- 同 lot 用 MES 补缺陷时，会带上最新一遍的全部 BIN。良率只把 BIN_NAME 为 F 的数量当作不良，其它 BIN 仍显示数量。
- 处置历史每一行增加「分析」，可直接打开该 Record 的数据分析。
